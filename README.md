
# ART STORE

An international e-commerce platform for selling original paintings.

## Project Goals

- Display paintings for international customers.
- Allow customers to browse and purchase artwork.
- Support suitable international payment methods.
- Support Bitcoin payments through a payment processor.
- Provide an administration dashboard.
- Track customer orders and transactions.

## Technologies

- HTML
- CSS
- JavaScript
- Python Flask
- MySQL
- Git and GitHub
